Architecture & SDK Integration

Rico acts as a transparent, high-concurrency gateway between client agents and upstream models.

OpenAI SDK Compatibility (Drop-in Replacement)
from openai import OpenAI

# Simply point your OpenAI SDK base_url to Rico!
client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="rico-dev-token",
    default_headers={"X-Team-ID": "team-ai-agents"}
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Analyze system requirements."}]
)

# Even if OpenAI encounters an outage, Rico transparently serves completion via fallback!
print(response.choices[0].message.content)
Direct Python Library & Model Router Usage
from rico import ModelMeshRouter, ChatCompletionRequest, ChatMessage

router = ModelMeshRouter()

# Execute chat through circuit-breaker mesh
response = await router.execute_chat(
    ChatCompletionRequest(
        messages=[ChatMessage(role="user", content="Hello")],
        team_id="team-analytics"
    )
)

print(response.model)                      # Model that fulfilled request
print(response.fallback_trace.fallback_triggered)  # False (or True if primary degraded)

Deploying Rico on Render

Rico is ready for one-click deployment on Render with an optional Redis instance for distributed sliding-window rate limiting.

1

Method A: One-Click Render Blueprint (Recommended)

Rico includes a production render.yaml that automatically provisions the Docker Web Service and private Redis instance.

render.yaml
services:
  - type: web
    name: rico-gateway-service
    env: docker
    dockerfilePath: Dockerfile
    plan: starter
    region: oregon
    healthCheckPath: /health
    autoDeploy: true
    envVars:
      - key: RICO_ENV
        value: production
      - key: PORT
        value: 8000
      - key: HOST
        value: 0.0.0.0
      - key: REDIS_URL
        fromService:
          type: redis
          name: rico-redis
          property: connectionString
      - key: OPENAI_API_KEY
        sync: false

  - type: redis
    name: rico-redis
    plan: starter
    region: oregon
    maxmemoryPolicy: allkeys-lru
2

Method B: Manual Web Service Setup via Render Dashboard

  1. Log in to Render Dashboard and click New + > Web Service.
  2. Connect your Git repository containing Rico.
  3. Set Environment to Docker (Render detects the root Dockerfile).
  4. Set Instance Type to Free or Starter.
  5. In Advanced > Health Check Path, enter: /health
  6. Configure Environment Variables:
    • PORT: 8000
    • RICO_ENV: production
    • REDIS_URL: redis://... (or leave empty for seamless in-memory fallback)
  7. Click Create Web Service. Render builds the container, runs health checks, and goes live with automated SSL!
